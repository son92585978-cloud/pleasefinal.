# 여행영단어 331 · V8 음성 설정

- 남성 / 여성 버튼으로 음성 선택
- 읽기 속도 0.5–1.5배 조절 (기본 0.8배), 단어와 모든 대화 읽기에 적용
- 선택한 음성·속도는 현재 브라우저에 저장
- 음성 직접 지정에서 기기의 영어 음성을 들어보고 각 버튼에 연결 가능
- 정지 또는 설정 변경 시 전체 읽기의 대기 중인 다음 문장도 취소

음성은 브라우저와 기기가 제공하는 영어 TTS를 사용합니다. 남녀 음성 모두를 제공하지 않는 기기도 있습니다. 자동으로 구분되지 않는 음성은 직접 지정하세요. 영어 음성이 없으면 기기의 TTS 설정에서 영어 음성을 추가해야 합니다. 추가 음성 API나 API 키는 사용하지 않습니다.

기존 V7의 331개 카드, 한글 검색 IME 수정, AI 자동완성과 설치 기능을 유지했습니다.
기존 사이트 파일을 이 ZIP의 파일로 교체하면 됩니다. 설치된 앱은 업데이트 후 다시 열어주세요.
