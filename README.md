# 여행영단어 331 · V9 실제 남녀 AI 음성

기존 V8의 기기 TTS 선택 방식을 실제 서로 다른 AI 음성으로 교체했습니다.

- 남성: Michael / 여성: Heart — 미국식 영어
- 기본 331개 단어와 여행 예문 전체에 두 음성 포함
- 읽기 속도 0.5–1.5배 조절, 음높이 유지
- 음성·속도 설정 자동 저장
- 단어, 개별 예문, 단어+예문 전체 읽기에 같은 설정 적용
- 정지, 음성·속도 변경, 다음·이전 카드 이동 시 현재 재생과 연속 읽기 취소
- AI 자동완성, 한글 검색 IME 수정, 연상법·뜻 등 기존 카드 내용 유지

## 사이트에 적용

1. ZIP을 압축 해제합니다.
2. 기존 GitHub Pages 저장소에 파일과 폴더를 같은 구조로 올립니다.
3. `audio` 폴더와 `neural` 폴더까지 반드시 포함합니다. `index.html`만 교체하면 음성이 나오지 않습니다.
4. GitHub Pages 반영 후 사이트를 새로고침합니다. 설치된 앱은 완전히 닫았다가 다시 여세요.
5. 카드에서 `남성 · Michael` / `여성 · Heart`를 선택하고 `목소리 들어보기`로 비교합니다.

이 앱은 웹사이트 주소로 실행하는 구성입니다. 휴대폰 파일 앱에서 HTML만 직접 열면 음성 파일을 읽지 못할 수 있습니다.

## 음성 사용 안내

기본 단어와 예문은 미리 생성한 음성을 재생하므로 기기에 남성 음성이 설치되어 있지 않아도 됩니다. API 키, 음성 서비스 가입 또는 음성 재생 요금은 없습니다. 인터넷 데이터 이용료는 사용 중인 요금제에 따릅니다.

추가하거나 수정한 문장은 브라우저 안에서 같은 Kokoro AI 모델로 음성을 생성합니다. 최초 사용 시 약 90MB의 모델과 실행 파일을 내려받으며, 기기 성능과 인터넷 속도에 따라 시간이 걸립니다. Wi-Fi를 권장합니다. 이때 입력 문장을 외부 음성 API에 보내지는 않습니다. 모델과 생성에 필요한 파일 다운로드에는 인터넷 연결이 필요합니다.

재생했던 기본 음성 묶음은 브라우저가 저장 공간을 허용하는 범위에서 캐시됩니다. 처음부터 모든 음성이 오프라인에 저장되는 것은 아닙니다. 새 문장 생성은 최신 Chrome 계열 브라우저를 권장합니다.

음성은 AI 합성 음성입니다. 실제 두 목소리 모델을 사용하며, 여성 음성의 음높이를 낮춰 남성처럼 만드는 방식이 아닙니다. 지나치게 느린 속도는 부자연스럽게 들릴 수 있으므로 0.8–1.0배부터 사용해보세요.

## 기존 AI 단어 추가

기존 AI 자동완성 연결 방법은 `AI_SETUP.md`를 참고하세요. 음성 기능과 별개의 기능이며, 기존 연결 설정을 그대로 사용합니다.

## 음성 구성

`audio/index.json`은 텍스트별 남녀 음성의 위치를 기록합니다. `.bin` 파일에는 여러 개의 독립적인 MP3가 들어 있습니다. 앱은 필요한 MP3만 분리해 재생합니다. `neural/worker.js`와 WASM 파일은 새 문장의 음성을 기기에서 생성할 때 사용합니다.

Kokoro-82M v1.0 / kokoro-js 1.2.1의 `am_michael`, `af_heart` 사용.
https://github.com/hexgrad/kokoro
https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX

관련 라이선스는 `neural` 폴더의 라이선스 파일 및 `THIRD_PARTY_NOTICES.md`에 있습니다.
