영어 회화 V7

travel-conversation.html을 열거나 기존 사이트의 같은 파일을 교체하세요.
기존 여행 회화와 저장 키는 유지했습니다. 같은 브라우저와 같은 사이트 주소에서 사용하세요.

영화·드라마 받아쓰기:
1. 원본 영상/음성 파일을 선택합니다.
2. 같은 버전의 영어 SRT/VTT 자막을 선택합니다.
3. 대사 듣기 → 받아쓰기 → 정답 확인 순서로 연습합니다.
4. 대사는 대사 보기 버튼을 눌러야 보입니다.

실제 영화·드라마 영상/음성은 포함하지 않았습니다. 이 모드는 TTS를 사용하지 않습니다. 기존 여행 회화 탭만 기기 TTS를 사용합니다.
원본은 브라우저를 다시 열 때 재연결해야 합니다. 자막과 기록은 브라우저에 저장됩니다. 백업 기능으로 다른 기기로 옮길 수 있습니다.

검증: 기존 회화 회귀 검사와 자막 해석·정오답·가리기·구간 타이밍·기록 저장 검사 통과. 실제 브라우저 실행은 환경 제한으로 검증하지 못했습니다. 실제 기기에서 파일 형식과 재생을 확인하세요.
