Scene Listening Lab v1
1. ZIP 압축을 해제합니다.
2. index.html을 브라우저로 열어 체험합니다.
3. PWA 설치는 Netlify Drop에 압축 해제한 폴더를 올린 후 HTTPS 주소에서 브라우저 '홈 화면에 추가'를 사용합니다.
4. 합법적으로 이용 가능한 SRT/VTT 자막과 음성/영상 파일을 각각 불러옵니다.
5. 저작권 보호 콘텐츠의 무단 다운로드, 추출 또는 재배포는 지원하지 않습니다.
참고: 이 버전에는 프렌즈 대사와 실제 배우 음성이 포함되지 않습니다. 시즌/에피소드 선택은 분류 UI이며, 자동으로 해당 회차 자료를 내려받지 않습니다.
