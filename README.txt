추가 내용
예문 보충 단어 997개 중 비교·활용 설명이 필요한 478개에 ‘비슷한 표현’과 ‘같이 기억하기’를 보강했습니다.
예문에서 영어 단어를 누른 뒤 단어장 아래쪽으로 내려가면 볼 수 있습니다.
- 비슷한 단어의 차이와 언제 사용하는지 설명
- 함께 외우는 표현과 영어 예문·한국어 해석
- 전치사·단어 형태·질문과 답변에서 흔히 헷갈리는 점
예: collect / pick up / receive, get / go / reach, borrow / lend / rent,
which / what, Can I help you?에 I'd like…로 답하는 이유 등.

유지한 내용
기존 단어·예문, 한글 발음, 연상법, 단어 및 예시 오답 저장, 무작위 순서, 이전 공부 위치 복귀 기능 유지.
이번 추가 설명은 앱에 포함된 데이터이며 AI API 호출을 추가하지 않습니다.

확인 사항
모바일 크기 브라우저에서 설명 표시·줄바꿈·스크롤, 예문 단어 이동, 단어 오답 추가/해제 및 재실행 후 유지,
기존 ❌ 노트에서의 표시, 랜덤 50번째 위치와 예시 순서 보존을 확인했습니다.
997개 보충 단어의 식별자·뜻·발음·연상·기존 대화가 이전 버전과 동일함을 검사했습니다.
실제 휴대전화 음성 재생은 이번 환경에서 검증하지 않았습니다.
