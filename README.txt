단어 기본형
- require를 제목으로 표시하고 requires는 예문 형태로 안내합니다.
- requires: 복수형 명사가 아닌 동사 현재형 3인칭 단수. 예문의 Our store policy와 that이 단수 주어이기 때문입니다.
- child / children: 기본형과 명사 복수형으로 안내합니다.
- go / goes / going, do / does / did, be / am / are / is / was / been도 분리 설명합니다.
- 예문 원문 철자는 그대로 둡니다. requires를 눌러도 require 카드가 열립니다.
- 활용형 철자로 검색해도 기본형이 검색됩니다.
- 같은 기본형의 단어·오답·개인 연상이 하나의 카드로 연결됩니다.
- clothes, trousers, customs 등은 무조건 끝의 s를 떼면 뜻이 달라지므로 독립 어휘와 설명을 유지합니다.
- 진행형, 과거/과거분사, 비교급·최상급, 소유격도 구분합니다.

발음·연상
교토·도쿄·오사카·싱가포르는 지명 표기를 명시하고 과하게 늘인 한글 표기를 정리했습니다.
require 리콰이어 / request 리퀘스트는 서로 다른 단어·발음으로 안내합니다.
‘리! 콰이어!’처럼 이름과 생소한 단어를 끊어 붙인 연상을 제거했습니다.
예문에서 requires 한 장을 보던 방식 대신 기본 단어 require의 연상을 보고 활용 이유를 확인합니다.
뜻만 외우라는 안내 문구가 남아 있던 항목을 소리·뜻 연결로 보강했습니다.
한글 표기는 읽기 보조이며 실제 영어 소리의 완전한 표기가 아닙니다.

이전 저장 데이터
활용형으로 체크했던 오답은 기본형 오답으로 합칩니다.
활용형에만 저장한 개인 수정은 기본형으로 연결합니다. 기존에 기본형 수정이 있으면 그 수정이 우선합니다.
변환 전 오답·개인 수정은 앱 저장소에 백업합니다.
공부 위치는 예전 카드 식별자를 새 기본형으로 연결해 복원합니다. 중복 활용형을 합쳐 카드 개수는 줄어듭니다.
개인적으로 고친 연상은 새 기본 연상보다 우선 표시됩니다.
기존 모든 예문 대화쌍을 보존했고, 뜻풀이·비슷한 표현도 연결했습니다.
이번 변경은 AI API 호출을 추가하지 않습니다.

검증
- 기존 오답·개인 수정·공부 위치가 기본형으로 연결되는지 확인
- 예문의 requires 클릭 → require 제목 → 3인칭 단수 설명 확인
- children → child와 명사 복수형 설명 확인
- 활용형 검색, 개인 연상 수정·재실행·오답노트 공유 확인
- 원래 보던 공부 단어로 복귀, 화면 오류·가로 넘침 검사
- 기존 모든 대화쌍 보존, 단어 제목 중복 및 연상·한글 발음 누락 검사
실제 기기의 음성 재생은 이번 환경에서 검증하지 않았습니다.
