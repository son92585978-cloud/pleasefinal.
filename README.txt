연상 기준
한국어 소리 연결 → 그 말 안에 뜻이 담긴 짧은 이야기 → 다시 외울 연결 순서.
particular: 파티 컬러는 꼭 빨강만 → 특정한
souvenir: 기념품을 수북이 넣어 → 기념품
withdraw: 위에서 드르륵 돈이 나와 → 인출하다
에서는 방금 확인한 예시 문구를 그대로 반영했습니다.
V22까지 수정한 내용을 포함하고, 남은 연결이 약한 항목을 보강했습니다.
복수·과거형은 기본 단어의 소리 연결을 공유합니다. 이름·숫자는 실제 이름·철자·수량으로 연결합니다.
이야기의 한국어 소리는 실제 영어 발음·어원과 동일하다는 뜻이 아니므로 듣기와 함께 사용하세요.
