연상법 수정
기본 단어 331개와 예문 단어 997개를 점검해 기본 단어 132개, 예문 단어 744개의 연상을 수정했습니다.
뜻이나 일반 여행 상황만 반복하는 항목에 소리 연결, 이미 아는 말, 실제 단어 구성의 연결 고리를 넣었습니다.
예: instead — ‘인스(턴트) 대신!’ / receive — 배구 리시브처럼 받기 /
withdrawal fee — ‘위에서 드르륵’ 인출 + ‘피 같은 요금’.
복수형·과거형은 기본 단어의 소리 연결을 이어 사용합니다.
이름·숫자는 실제 이름·철자·수량의 연결을 사용합니다.
소리가 비슷한 한국어 이야기와 실제 영어 어원·문법은 다릅니다. 듣기 버튼으로 실제 발음도 확인하세요.
