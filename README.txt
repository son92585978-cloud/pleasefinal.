기존 단어 활용표
기존 기본 단어장 318개 단어·표현 전체에 품사에 맞는 활용표 또는 설명을 넣었습니다.
동사는 과거형 / 과거분사 / -ing형 / 현재 3인칭 단수형을 바로 볼 수 있습니다.
명사는 단수·복수형을, 실용적인 형용사에는 비교급·최상급을 표시합니다.
고정 표현·전치사·조동사에는 잘못된 -s나 -ed를 만들지 않고 변화가 없는 이유를 설명합니다.
구동사는 뒤 표현을 유지해 check in → checked in / checked in / checking in / checks in처럼 표시합니다.
문장형 카드에는 관련 동사의 변화표임을 따로 명시합니다.

예
- take → took / taken / taking / takes
- withdraw → withdrew / withdrawn / withdrawing / withdraws
- passport → passports
- permit → permitted / permitted / permitting / permits
- baggage: 이 뜻에서는 보통 복수 -s를 붙이지 않음

유지

뜻·발음·연상·예문·비슷한 표현/같이 기억하기는 바꾸지 않았습니다.
연상 개인 수정, 오답노트, 공부 위치 복원은 유지합니다.
