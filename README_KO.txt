영어 회화 V8

travel-conversation.html을 브라우저로 열거나 기존 사이트의 같은 파일을 교체하세요.
실제 영화 원본에서 추출한 음성이 HTML 안에 포함되어 있습니다. 별도 파일 업로드 없이 바로 연습할 수 있습니다.

기본 작품: Sintel 11개 대사 + Tears of Steel 33개 대사 (총 44개)
작품 선택 → 이 대사 듣기 → 영어 입력 → 정답 확인.
영어 대사와 한국어 해석은 대사 보기 버튼을 눌러야 나타납니다.
음성은 실제 원작의 성우/배우 목소리이며 TTS가 아닙니다.
기본 작품은 영상 화면이 아닌 원본 음성 클립으로 제공합니다.

기존 여행 회화는 별도 탭에서 그대로 사용할 수 있으며 이 탭의 듣기만 기기 TTS입니다.
기존 기록은 같은 브라우저와 같은 사이트 주소에서 유지됩니다.
학습 기록 내보내기/가져오기로 받아쓰기 기록을 백업할 수 있습니다.
선택 기능으로 내 영상/음성과 영어 SRT/VTT 자막을 추가할 수 있습니다.

검증: 기존 회화 회귀 검사, 기본 음원 자동 연결, 자막 해석, 정오답, 대사/해석 가림, 구간 타이밍/정지, 기록 보존 검사 통과.
음원 전체 디코딩 검사 통과. 환경 제한으로 실제 브라우저 화면·오디오 출력은 검증하지 못했습니다.
