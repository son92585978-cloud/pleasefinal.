새 기능
- 💬: 기존 단어 카드의 대화 문장을 별도 목록에서 연습합니다.
- 기본 한국어 해석이 먼저 보이고, 나눈 해석과 영어는 각각 보기/가리기가 가능합니다.
- 한글/영어/원래 단어로 예문을 검색할 수 있습니다.
- 영어를 펼쳐 단어를 누르면 기존 단어장 또는 예문 보충 단어장이 열립니다.
- collect를 포함해 빠져 있던 997개 표기 형태의 보충 카드를 추가했습니다. 복수형·활용형·축약형은 예문에 나온 형태로 포함됩니다.
- 보충 카드는 뜻과 실제 사용 대화를 제공합니다. 모든 보충 카드에 개별 발음 연상이나 한글 발음 표기가 추가된 것은 아닙니다.
- 보충 카드는 검색/예문에서 찾고 오답에 넣을 수 있습니다. 기존 331개 학습 순서에는 끼워 넣지 않습니다.
- 돌아가기는 보던 예문, 검색어, 해석/영어의 펼침 상태와 원래 학습 위치를 복원합니다.
- caf 오타를 cafe로 수정했습니다.

검증
휴대폰 크기의 자동 브라우저 테스트: 예문 초기 가림, collect 이동, 펼침 상태 복원, 무작위 50번째 카드와 정확한 순서 복원, 검색 결과 없음에서 뒤로가기, 새로고침 후 예문 쪽 복원, 모든 기존 대화 단어 연결을 확인했습니다.
기존 검색/오답 화면의 중첩 뒤로가기, 새로고침, 마지막 오답 해제도 확인했습니다.
휴대폰 실기기 음성 재생은 별도로 확인하지 못했습니다. 기존 audio-engine.js와 neural 폴더를 사용하며 새 단어는 기존 로컬 음성 생성 기능에 의존합니다.

이번 예문 목록/단어장 기능은 OpenAI API를 호출하지 않습니다.
기존 AI 자동 채우기 기능을 별도로 사용하면 기존 API 설정과 요금이 적용됩니다.
