여행 영어 V17 — 예시 전체 오답노트
작성일: 2026년 10월 21일 (한국시간)

설치
압축을 풀고 GitHub pleasefinal. 저장소 맨 위의 index.html, 404.html, sw.js 세 파일을 교체한 뒤 Commit changes로 저장하세요.
배포 완료 후 앱을 완전히 닫았다가 다시 열어 주세요. 기존 audio, neural 폴더와 나머지 파일은 그대로 두세요.
학습/오답 기록을 유지하려면 사이트 데이터나 저장공간을 삭제하지 마세요.

사용법
1. 단어 카드의 예시 1 또는 예시 2 아래에서 ‘❌ 이 예시 전체 오답 체크’를 누릅니다.
2. 해당 예시의 질문과 답변이 한 묶음으로 저장됩니다. 예시 1과 예시 2는 각각 체크할 수 있습니다.
3. 단어 카드의 ‘❌ 예시 오답노트 보기’, 또는 💬 예문 목록의 ‘❌ 예시 오답노트’를 눌러 모아 봅니다.
4. ‘✅ 이 예시 오답 해제’를 누르면 그 대화 묶음만 오답노트에서 빠집니다.
5. 뒤로가기/돌아가기 버튼으로 보던 화면으로 복귀합니다.

💬 예문 목록도 질문/답변이 떨어지지 않도록 대화 묶음 단위로 표시합니다. 한 쪽에 최대 6개 예시를 표시합니다.
한국어 뜻은 먼저 보이고, 나눈 해석과 영어는 각각 보기/가리기가 가능합니다. 영어 단어를 누르면 단어장으로 이동합니다.
같은 질문과 답변 전체가 여러 단어 카드에 반복되는 경우 하나의 대화로 모읍니다.
예시 오답은 기존 단어 오답과 별도로 현재 브라우저에 저장됩니다. API 호출/요금은 없습니다.
V16.1의 터치 스크롤 수정도 포함되어 있습니다.

검증
모바일 브라우저 자동 테스트: 예시 1/2 개별 체크, 질문/답변 전체 표시, 새로고침 후 저장 유지, 단어 오답과 분리, 영어 초기 가림, 단어장 이동 후 복귀, 마지막 예시 해제, 페이지 보정, 예문 펼침 상태/쪽 복원, 무작위 50번째 단어 및 전체 순서 복원, 터치 스크롤을 확인했습니다.
실제 사용자 휴대폰에서의 실행 및 음성 재생은 별도로 확인하지 못했습니다.
