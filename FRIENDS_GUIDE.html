FRIENDS HYBRID ENGLISH V6

자료가 보이지 않을 때

첫 화면은 내장 자료 목록입니다. 장면의 바로 학습을 누르면 듣기·받아쓰기로 바로 들어갑니다. 개인 자막 저장소를 기다리지 않고 내장 자료를 먼저 표시합니다. 자료 파일 누락은 빈 화면 대신 오류 안내로 표시합니다.

제작된 콘텐츠

S1E1–E6 각각 3장면·24문장, 합계 18장면·144문장입니다. 기존 36문장에 새로운 108문장을 추가했습니다. 표현 설명 146건과 응용 예문 438개가 연결되어 있습니다. 모두 독립 창작 대화입니다.

V6 목표 236화·708장면·5,664문장 중 아직 230화·690장면·5,520문장이 부족합니다. 현재 파일은 V6 부분 업데이트이며 전체 완성본이 아닙니다. 로컬 자막은 추가 학습을 위한 선택 기능입니다.

음성과 화면

사전 제작 AI 음성 0개, AI 동영상 0개. 브라우저 TTS와 독립 캐릭터 CSS 애니메이션을 제공합니다. 화자별 목소리를 선택할 수 있지만 기기에 미국 영어 음성이 충분히 설치되어 있어야 합니다. 기기 음성은 오프라인 지원 여부가 기기에 따라 다르며 온라인 음성은 인터넷이 필요할 수 있습니다. 이 앱에 유료 TTS API·비밀키는 추가하지 않았습니다. 자연스러운 감정·강세·연음 품질은 검증하지 않았습니다.

로컬 자막

SRT/VTT/TXT 또는 JSON 배열을 불러와 미리보기 후 저장합니다. JSON 예: [{"text":"This is my own sample.","start":1,"end":4}]. TXT나 시간이 없는 JSON은 시작·종료를 직접 지정해야 합니다. 여러 문장이 한 자막에 있으면 분리하지만 원래 구간을 공유하므로 문장별 시간을 직접 조절하세요. 모든 로컬 파일은 싱크 미검증입니다. 사용자 자막의 번역·문법·IPA는 자동 생성하지 않습니다.

저장과 복귀

기존 travelWork331:* 및 friends-master:v1 기록을 유지합니다. 기존 자막은 최초 실행 시 IndexedDB로 복사하며 원래 localStorage 값은 지우지 않습니다. 자막 교체는 새 ID를 사용해 이전 채점 기록이 새 문장에 잘못 적용되지 않도록 합니다. 이전 기록은 남지만 교체·삭제한 원문이 없으면 바로 열 수 없습니다. 자료·설정의 백업은 기록과 자막을 포함하고 미디어와 비밀키는 제외합니다.

표현을 저장하면 기존 단어장의 사용자 카드에 IPA·활용형·원문·출처·학습 통계가 함께 저장됩니다. 틀린 문장은 기존 오답 카드에 연결됩니다. 기기 뒤로가기 및 화면의 이전 버튼은 학습 입력·채점·공개 상태·스크롤을 복원합니다.

오프라인

온라인 첫 방문 시 학습 화면과 기존 단어 해설을 캐시합니다. 기존 녹음 음성 파일은 실제로 재생하여 캐시된 파일만 오프라인에서 이용할 수 있습니다. 새 창작 대화는 브라우저 TTS의 설치된 음성에 의존합니다. 처음 방문한 뒤 준비가 끝나기 전에 연결을 끊으면 오프라인 자료가 부족할 수 있습니다. 앱 저장 데이터를 삭제하면 개인 학습 기록과 로컬 미디어가 사라질 수 있으니 업데이트를 위해 사이트 데이터를 삭제하지 마세요.

채점

단어 정렬 편집 거리 기반입니다. 철자 오류, 누락, 추가, 순서 이동을 표시합니다. don't/do not, I'll/I will 같은 명확한 축약은 동등 처리합니다. 's와 'd는 is/has, would/had 중 무엇인지 불명확하므로 자동 확장하지 않습니다. 영어 전체 의미를 판단하는 AI 채점은 아닙니다.

실행 검수 범위

DOM 실행 테스트에서 시즌·회차·문장 이동, 받아쓰기, 채점, 정답 가림, 표현/분해 설명, 기존 단어장·검색·IPA·오답 연동, 즐겨찾기, History 뒤로가기·스크롤 복원, 재실행 저장 복원, SRT/VTT/TXT/JSON 가져오기·교체·삭제, 구간 반복 제어, 백업 저장 구조 보존을 확인했습니다. 음성 엔진·미디어 재생·IndexedDB는 테스트 대역을 사용했으므로 실제 기기 청취 품질이나 코덱 지원을 검증한 것은 아닙니다.

서비스 워커는 모의 Cache/Network에서 설치·갱신·오프라인 파일 반환을 검증했습니다. 실제 Android/iOS 시스템 뒤로가기, 홈 화면 설치, 실제 브라우저 오프라인 재생과 GitHub 배포 결과는 미검증입니다. 로컬 Chromium은 실행 권한 제한으로 기동하지 못했고 원격 브라우저는 로컬 검수 서버에 연결할 수 없었습니다.

추가 수정: 정답 재시도 성공 시 기존 오답노트 연결 해제, 같은 표현의 저장 카드 식별, 뒤로가기 복원 시 음성 핸들러 재연결, TTS 취소 이벤트 충돌 방지, 자막 약어·소수 분리 개선, 손상된 기존 기록 덮어쓰기 차단, 저장 공간 부족 안내 유지. 업데이트 ZIP은 원본에 덮어쓴 후 동일 테스트를 재실행했습니다.
