# 여행영어 V49 검수 수정본

먼저 `검수결과_먼저읽기.md`를 확인해 주세요. 이 결과물은 전수검수 완료판으로 인증되지 않았습니다.

## GitHub Pages에 적용

ZIP을 풀고 index.html과 함께 모든 JS, manifest, sw.js, 아이콘 파일을 기존 사이트 파일과 같은 위치에 올리세요. ZIP 파일 자체를 사이트 파일로 올리는 방식은 아닙니다. 하위 폴더로 제공하는 GitHub Pages에서도 상대 경로를 사용하도록 구성했습니다. 실제 배포·설치·오프라인 동작은 미검증입니다.

기존 학습 기록을 유지하려면 기존에 사용하던 사이트 주소에서 파일을 교체해 이용하세요. 브라우저 데이터나 사이트 저장소를 삭제하지 마세요. 다른 호스트나 브라우저로 옮기면 기록이 자동 전송되지 않습니다.

원래 음성 파일은 첨부본에 없었습니다. 현재 버전은 기기 영어 읽기 기능을 사용하므로 기존 Michael·Heart 음성과 다릅니다.

## 로컬 실행과 코드 검사

```sh
python3 -m http.server 8000
```

브라우저에서 로컬 서버의 이 폴더를 열어 사용합니다. HTML 파일만 직접 여는 방식은 설치·캐시 기능에 적합하지 않습니다.

```sh
node audit_sources/check.cjs
```

Node 검사에는 별도 패키지가 필요 없습니다. 이 검사는 JavaScript, 데이터, HTML 문자열 및 가상 방문 기록만 확인합니다. 보고서의 ‘실제 브라우저 미검증’을 대신하지 않습니다.
