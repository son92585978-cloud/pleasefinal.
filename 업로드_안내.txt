이전 V2 업데이트 ZIP에는 반드시 필요한 JS 파일 일부가 빠져 있었습니다.
이 패키지는 이전 파일이 일부 누락돼도 동작하도록 필요한 업데이트 파일을 모두 묶었습니다.
회화 V2는 데이터·그림·학습 기능을 HTML에 포함해 독립적으로 열리게 했습니다.

업로드 순서:
1. ZIP을 먼저 압축 해제하세요. ZIP 자체를 GitHub에 올리면 안 됩니다.
2. GitHub 저장소의 최상위 폴더에서 Add file > Upload files 선택.
3. 이 폴더 안의 HTML 3개 + JS 파일들 + sw.js를 한 번에 모두 끌어다 놓으세요.
4. 기존 파일과 같은 이름은 덮어쓰고, 나머지는 새 파일로 추가합니다.
   기존의 다른 파일들은 삭제하지 마세요.
5. Commit changes 한 번만 누르면 됩니다. GitHub Pages 반영 후 앱을 열어 확인하세요.

구성:
- index.html: 기존 단어장 + 1회 클릭 업데이트 적용
- travel-conversation.html: 기존 800문장 학습 보존
- travel-daily-conversation.html: 상황별 실전회화 V2 (핵심 의존성 내장)
- study-quick-nav.js: 세 화면 하단 전환
- travel-additions.js / travel-beginner.js / travel-enhance.js / travel-grade.js:
  기존 800문장 학습 필수 스크립트
- v2-scenes-data.js / v2-scene-art.js / v2-ui.js:
  V2 백업 및 차후 수정용 (회화 화면은 이 내용도 내장)
- sw.js: 새 버전 캐시 및 오프라인 지원
